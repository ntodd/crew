# Crew 0.1.0

The first release. It exists so a control plane can be stood up from a
published image, and so the next release can be the first one a
control plane updates to from its Deployment page.

## What's in it

Everything on `main` as of this tag: the control plane (SQLite and
Postgres images, amd64 and arm64), the agent and cache for linux-amd64,
linux-arm64 and darwin-arm64, and the guest images. This is the first
release with an x86_64 guest image, so `linux-metal` and `linux-vm`
boxes on Intel and AMD hosts can run jobs.

## Before you install it

- The hardware checks in `docs/releasing.md` weren't run for this
  release: neither the e2e suite against a test App and repo nor the
  aarch64 conformance suite on a `mac-vm` box. CI's checks and the
  agents' and control plane's smoke tests passed. Treat 0.1.0 as a
  bootstrap release.
- The x86_64 guest image boots under Firecracker and stops gracefully,
  but the driver conformance suite hasn't run on an x86_64 box yet.
- Nothing to migrate: there's no earlier release.
