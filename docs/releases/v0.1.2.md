# Crew 0.1.2

Jobs run. On 0.1.0 and 0.1.1, every job VM on every box refused to
start its runner.

## What changed

- **Runners start.** The guest refuses to start a runner
  whose JIT config doesn't turn off the runner's self-update, and
  GitHub's JIT configs never do: they leave `DisableUpdate` out of
  `.runner`. Every VM failed seconds after it
  booted (`refusing to start the runner: update_not_disabled`), and
  three in a row quarantined the box. The control plane now sets
  `DisableUpdate: true` in the config it sends, so guest images from
  0.1.0 and 0.1.1 work too.

## Before you install it

- Nothing to migrate, and the protocol is unchanged.
- The hardware checks in `docs/releasing.md` weren't run for this
  release.

## Supply-chain review

No bumps.
