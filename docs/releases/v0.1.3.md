# Crew 0.1.3

A cleanup of the Runs page, and a run page you can sit on and watch a
run finish.

## What changed

- **Runs page.** Full width, with the filters on one row. Branch, PR
  and actor are one search box: a word matches part of a branch or an
  actor, or a PR number. `#718` matches only that PR, and `branch:`,
  `pr:` and `actor:` match exactly. A "Crew jobs only" checkbox hides
  runs that had no job for Crew. The job bars, durations and ages line
  up from row to row, and the repo, PR, branch and commit link to
  GitHub. When the filters hide everything, the page says so and offers
  to clear them, where it used to say "No runs yet".
- **Run page.** Full width and live. Job and run changes show up within
  a quarter of a second; while the run is going, its steps, VMs and
  boxes reload every 5 seconds, and running times count up every second
  in the browser. A menu switches between a run's attempts. Each job has
  a step bar: hover a step to see which it is and how it went, click it
  to go to it on the job page. The box a job ran on links to the box,
  and hovering it shows that box's card from the dashboard.
- **Jobs that aren't Crew's** show how they went on GitHub, so the Runs
  page's bars are green instead of gray. GitHub's mark next to the
  status says whose they were.
- **Status icons are solid** wherever a run's or a job's status shows.
- **The job page** shows the guest's live steps while a job runs,
  numbered the same as the run page's step bar.
- CI can build the guest images on Crew (`CREW_CI=on`), with a timeout
  on each long build step.
