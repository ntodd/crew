# Crew 0.1.4

Firecracker boxes keep their firewall verified after a Tailscale update.

## What changed

- **Crew shares the mangle table.** The connection cap lives in
  iptables-nft's mangle table, and `crew-vmctl nft-verify` required
  that table to be exactly Crew's. Tailscale 1.104.5 adds two connmark
  rules to it. So once a box's Tailscale system extension updated and
  the box rebooted, every check failed, the box reported "Firewall not
  verified", and it got no VMs. Now Crew owns only its `CREW-CONNLIMIT`
  chain and the first rules of mangle's `INPUT` and `FORWARD`, which
  jump into it. `nft-verify` checks those and ignores everything else.
  crew-net loads them with `iptables-nft-restore --noflush`, so it no
  longer wipes Tailscale's rules either.

## Before you install it

- Nothing to migrate, and the protocol is unchanged.
- A box that shows "Firewall not verified" since a Tailscale update
  verifies again once its agent is on 0.1.4. It doesn't need a
  restart.
- The hardware checks in `docs/releasing.md` weren't run for this
  release.
