# Crew 0.1.5

Mac boxes keep crew-vzd running after they enroll.

## What changed

- **Enrolling no longer locks crew-vzd out.** On a Mac, crew-vzd runs as
  `_crewvm` and starts `agent/current/bin/crew-vz`. The installer makes
  `agent/` 0750 so it can, but the agent set `agent/` to 0700 when it
  enrolled. From then on launchd couldn't start crew-vzd ("Missing
  executable", exit 78), and the box reported "Firewall not verified"
  and got no VMs. A box whose crew-vzd was already running kept working
  until crew-vzd restarted. The agent now leaves an existing `agent/`
  alone. `identity.json` is still 0600.

## Before you install it

- Nothing to migrate, and the protocol is unchanged.
- On a Mac box that shows "Firewall not verified", or that enrolled on
  0.1.4 or earlier, run
  `sudo chmod 0750 "/Library/Application Support/Crew/agent"`. 0.1.5
  doesn't change the mode of a directory that's already there.
- The hardware checks in `docs/releasing.md` weren't run for this
  release.
