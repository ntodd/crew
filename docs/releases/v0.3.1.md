# Crew 0.3.1

Usage now shows what your Crew jobs would have cost on GitHub-hosted
runners.

## GitHub Actions spend on Usage

For the selected 7, 30 or 90 days, Usage shows an estimated dollar total
for running the same jobs on comparable GitHub-hosted Linux runners.
Expand it to see billable minutes, the per-minute rate and the estimated
spend for each runner size.

Crew rounds each finished job up to the minute, the way GitHub bills,
and matches it to the smallest GitHub-hosted VM with the job's
architecture and at least its vCPUs and memory. Standard runners are
free for public repositories, so a public repo's job that fits one (up
to 4 vCPUs and 16 GiB) counts as $0. The estimate assumes the same
runtime on GitHub, uses each repository's current visibility and the
box's architecture, and leaves out plan allowances and storage. Rates
are GitHub's published prices as of November 27, 2026. Minutes it
couldn't price, such as a job larger than any GitHub runner or one whose
size or repository is unknown, are listed separately.

## Upgrading

Nothing to do beyond the 0.3.0 notes. There are no migrations and no
changes to `compose.yml`. If you're coming from 0.2.x, read the
[0.3.0 notes](v0.3.0.md) first: mac-vm workers drain, new boxes need
approval, and Compose installs need the new `compose.yml`.
